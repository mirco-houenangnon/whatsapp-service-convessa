Scanner le QR Code

Pour connecter ce compte WhatsApp, rendez-vous sur le Panel WhatsApp, puis scannez le QR code affiché avec votre téléphone.


Comment faire :

  1. Ouvrez WhatsApp sur votre téléphone
  2. Allez dans Appareils connectés
  3. Appuyez sur Connecter un appareil
  4. Scannez le QR code sur le panel
