# Forfaits et Paiement

## Les forfaits CONVESSA

CONVESSA propose plusieurs forfaits adaptés à vos besoins. Consultez [Voir les forfaits](/pricing) pour les prix exacts et les détails à jour.

### Types de forfaits

- **Forfait messages limités** : un quota de messages par mois
- **Forfait illimité** : aucune limite sur les messages envoyés

### Comment choisir son forfait ?

- Si vous envoyez moins de 500 messages par mois → forfait de base
- Entre 500 et 5000 messages → forfait intermédiaire
- Plus de 5000 messages → forfait illimité ou premium

## Passer à un forfait payant

1. Allez sur [Voir les forfaits](/pricing)
2. Choisissez le forfait qui correspond à vos besoins
3. Cliquez sur "Choisir ce forfait"
4. Sélectionnez votre moyen de paiement

## Moyens de paiement

### FedaPay

FedaPay est disponible pour les paiements par :
- Mobile Money (MTN, Moov en Bénin)
- Carte bancaire (Visa, Mastercard)

Le paiement s'effectue dans un nouvel onglet sécurisé FedaPay.

### KKiaPay

KKiaPay est disponible pour les paiements Mobile Money en Afrique de l'Ouest.

## Activation après paiement

Après validation du paiement :
1. Votre forfait est activé automatiquement (délai maximum : 2 minutes)
2. Vous recevez une notification de confirmation
3. Votre tableau de bord se met à jour avec le nouveau quota

Si l'activation tarde plus de 5 minutes après paiement confirmé, contactez le support via [Contacter le support](/contact).

## Notifications de quota

CONVESSA vous prévient automatiquement par message WhatsApp lorsque :
- Vous atteignez 80% de votre quota mensuel
- Vous atteignez 95% de votre quota mensuel
- Votre abonnement expire dans moins de 7 jours

Ces notifications anti-spam ne sont envoyées qu'une seule fois par seuil.

## Code de parrainage

Si vous avez reçu un code de parrainage, entrez-le lors de votre inscription pour bénéficier d'avantages spéciaux (quota offert, réduction...).

## Renouvellement

Les forfaits CONVESSA ne se renouvellent pas automatiquement. À l'expiration, vous recevez un rappel WhatsApp. Vous devez renouveler manuellement depuis [Voir les forfaits](/pricing).

## Questions sur la facturation

Pour toute question sur votre paiement ou votre facture, contactez le support via [Contacter le support](/contact) ou par WhatsApp.
