# Présentation de CONVESSA

## Qu'est-ce que CONVESSA ?

CONVESSA est une plateforme SaaS (Software as a Service) qui permet d'envoyer des messages WhatsApp en masse via une API REST. Elle s'adresse aux entreprises, développeurs et particuliers qui souhaitent automatiser leurs communications WhatsApp.

CONVESSA s'écrit avec un E — C-O-N-V-E-S-S-A. Ne pas confondre avec "Convassa" ou "Convaza".

## Ce que permet CONVESSA

- Envoyer des messages texte WhatsApp par API
- Envoyer des images, documents, vidéos et fichiers audio
- Envoyer des messages à des groupes WhatsApp
- Gérer une ou plusieurs sessions WhatsApp
- Suivre les envois via un tableau de bord
- Automatiser des workflows de communication

## Pour qui ?

- **Développeurs** : intégration API REST dans n'importe quelle application
- **Entreprises** : notifications clients, alertes, confirmations de commandes
- **Marketeurs** : campagnes de communication WhatsApp
- **Particuliers** : automatisation de messages personnels

## Architecture

CONVESSA fonctionne comme un pont entre votre application et WhatsApp :

1. Vous connectez votre numéro WhatsApp en scannant un QR code
2. Vous obtenez une clé API unique
3. Vous envoyez vos requêtes HTTP à l'API CONVESSA
4. CONVESSA transmet les messages via WhatsApp
