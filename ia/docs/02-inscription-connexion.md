# Inscription et Connexion

## S'inscrire sur CONVESSA

### Via Google

1. Cliquez sur "Se connecter avec Google" sur la page d'accueil
2. Choisissez votre compte Google dans la fenêtre qui s'ouvre
3. Autorisez CONVESSA à accéder à votre profil
4. Vous êtes automatiquement connecté et redirigé vers le tableau de bord

### Via GitHub

1. Cliquez sur "Se connecter avec GitHub"
2. Autorisez l'application sur GitHub
3. Vous êtes redirigé vers le tableau de bord

### Via Email/Mot de passe

1. Cliquez sur "Créer un compte"
2. Entrez votre email et choisissez un mot de passe
3. Vérifiez votre email si un lien de confirmation est envoyé
4. Connectez-vous avec vos identifiants

## Se connecter

1. Accédez à la page d'accueil de CONVESSA
2. Cliquez sur "Se connecter"
3. Choisissez votre méthode de connexion (Google, GitHub, Email)
4. Vous êtes redirigé vers votre tableau de bord

## Problèmes de connexion courants

### Erreur 403 après connexion

Vérifiez que votre compte n'a pas été suspendu. Contactez le support si le problème persiste.

### Le bouton Google ne répond pas

Vérifiez que les popups ne sont pas bloqués par votre navigateur. Autorisez les popups pour le site CONVESSA.

### Mot de passe oublié

Utilisez le lien "Mot de passe oublié" sur la page de connexion pour recevoir un email de réinitialisation.

## Sécurité du compte

- Votre session reste active pendant 7 jours
- Vous pouvez vous déconnecter à tout moment depuis le menu utilisateur
- Chaque connexion depuis un nouvel appareil est enregistrée pour votre sécurité
